# DreamLab AI logo options

**Chosen (October 2026): option 4, the golden field.** The live assets are in
`public/brand/` (`mark`, `mark-animated`, `lockup`, `lockup-animated`, app icons,
`logo-512.png` for search engines), plus `public/favicon.svg`, `favicon.ico` and
`apple-touch-icon.png`. Regenerate with `node docs/brand/logo/build.mjs`, then
copy and rasterise as in the commit that introduced `public/brand/`.

Open `preview.html` in a browser to compare every option on dark and light
backgrounds at real sizes. All files are generated by `build.mjs`; edit the
geometry there and run `node docs/brand/logo/build.mjs`.

| Option | Files | Idea |
|---|---|---|
| 1 · Classic | `01-classic-lockup*.svg` | The bowl, rising constellation and magenta wisp from the old raster logo, with an italic "DreamLab AI" wordmark in a cyan-to-violet gradient. Static, animated, white or ink mono, and `-consulting` versions with a CONSULTING line. The bowl comes from the collective's lowercase "dreamlab" logo, so use it only if you want a family resemblance. |
| 2 · Mark | `02-mark*.svg` | The bowl on its own, including a simplified favicon cut that reads at 16px (to replace the current white heart). |
| 3 · Header, evolved | `03-header-constellation*.svg` | Today's spaced capitals, now DREAMLAB AI; the cyan dot becomes a three-node constellation. |
| 4 · Golden field | `04-golden-field*.svg` | The hero's golden-angle seeds spiralling into a glowing core, the "dream" forming in the lab. |
| 5 · Diamond | `05-diamond-*.svg` | The LinkedIn company mark redrawn as vectors: nested diamonds, violet to blue, DREAMLAB over AI CONSULTING LTD. Stacked and horizontal, animated (frame draws, gem turns), mono, and a favicon that holds up at 16px. |
| 6 · Constellation diamond | `06-constellation-diamond*.svg` | Hybrid of 5 and 3: the diamond's corners are linked nodes around a central gem. Animated (links draw, nodes light in turn). Busier than 5 at 16px. |

Every letter is a vector path, so no font is needed. Each file is
self-contained with no scripts or external references. Animated files use CSS
inside the SVG and stop for visitors who prefer reduced motion.

This folder is outside `public/`, so nothing here is deployed. Once an option is
chosen, the favicon set, the web-manifest icons (192 and 512px), the
Organization logo in structured data and `logo_url` in
`forum-config/dreamlab.toml` should all move to it.

## Naming

Lowercase **dreamlab** is the North West creative-technology collective, with
its own logo. This company is **DreamLab AI Consulting Ltd**; its marks read
"DreamLab AI", with "CONSULTING" as an optional descriptor line.
