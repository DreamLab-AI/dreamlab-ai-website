Chapter 5: Assessment - Validating Your Mastery

Introduction: Proving Your New Skills

This assessment validates that you've mastered VS Code as your AI command centre. It combines knowledge checks with practical demonstrations.

Time: 10 minutes Passing Score: 80% (24/30 points) Format: Multiple choice, practical tasks, and reflection

Part 1: Knowledge Check (10 points)

Question 1: Core Concepts (2 points)

What is the primary advantage of using VS Code with direct AI integration over web-based AI tools?

A) It's faster to load B) It maintains project context and allows batch processing C) It has better graphics D) It's free

Answer: B

Question 2: Extensions (2 points)

Which extension type is NOT typically needed for an AI-enhanced document workflow?

A) Markdown support B) AI assistant (Continue, Copilot) C) Game development tools D) Version control (GitLens)

Answer: C

Question 3: AI Integration (2 points)

What's the keyboard shortcut to invoke AI assistance in Continue?

A) Ctrl+A B) Ctrl+I C) Ctrl+P D) Ctrl+Z

Answer: B

Question 4: Project Structure (2 points)

Why is organizing files into folders important in VS Code?

A) It looks professional B) It helps AI understand context and improves suggestions C) It's required by VS Code D) It saves disk space

Answer: B

Question 5: Workflow Efficiency (2 points)

What's the most efficient way to create repetitive document structures?

A) Copy-paste from old files B) Type everything manually C) Use snippets with AI enhancement D) Download templates from the internet

Answer: C

Part 2: Practical Skills (15 points)

Task 1: Quick Setup (3 points)

Instructions: Create this structure in under 60 seconds:

assessment-project/
├── documents/
├── research/
└── README.md

Evaluation Criteria:

  • ✓ Correct structure (1 point)
  • ✓ Completed in < 60 seconds (1 point)
  • ✓ README contains project description (1 point)

Task 2: AI-Enhanced Content (4 points)

Instructions:

  1. Create sample-document.md
  2. Write one sentence about version control
  3. Use AI to expand it into a 100-word paragraph
  4. Add a relevant Mermaid diagram

Evaluation Criteria:

  • ✓ File created correctly (1 point)
  • ✓ AI expansion successful (1 point)
  • ✓ Content makes sense (1 point)
  • ✓ Diagram added and renders (1 point)

Task 3: Snippet Creation (4 points)

Instructions: Create a snippet that generates this template:

# Project Status Update - [DATE]

## Progress
-

## Challenges
-

## Next Steps
-

Evaluation Criteria:

  • ✓ Snippet created (1 point)
  • ✓ Prefix triggers expansion (1 point)
  • ✓ Date auto-inserts (1 point)
  • ✓ Tab stops work correctly (1 point)

Task 4: Multi-File Operation (4 points)

Instructions:

  1. Create 3 files with related content
  2. Use AI to generate content for each
  3. Create an index file linking to all three
  4. Test that links work

Evaluation Criteria:

  • ✓ Three files created (1 point)
  • ✓ AI-generated content (1 point)
  • ✓ Index file with links (1 point)
  • ✓ Navigation works (1 point)

Evaluation:

  • Specific example (1 point)
  • Clear before/after comparison (1 point)
