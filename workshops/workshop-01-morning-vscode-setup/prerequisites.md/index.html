Prerequisites - Workshop 01 Morning: VS Code Setup

Before You Begin

This workshop transforms your computer into a professional AI command centre. Ensure you meet these requirements for the best experience.

Required Knowledge

Essential Skills

  • ✅ Basic Computer Literacy

    • Can install software
    • Comfortable with files and folders
    • Basic typing skills
    • Can navigate web browsers

  • ✅ No Coding Experience Required

    • This is NOT a programming workshop
    • We focus on document creation and AI integration
    • Everything is explained from first principles

Helpful (But Not Required)

  • 📝 Experience with Microsoft Word or Google Docs
  • 📧 Familiarity with email and web applications
  • 📁 Basic understanding of file organization

Technical Requirements

Hardware Specifications

Minimum Requirements:

  • Processor: Dual-core CPU (2015 or newer)
  • RAM: 4GB minimum, 8GB recommended
  • Storage: 2GB free disk space
  • Display: 1280x720 resolution minimum

Recommended Specifications:

  • Processor: Quad-core CPU
  • RAM: 8GB or more
  • Storage: 5GB free (for extensions and projects)
  • Display: 1920x1080 or higher

Operating System

Supported Platforms:

  • ✅ Windows 10 or 11 (64-bit)
  • ✅ macOS 10.15 (Catalina) or newer
  • ✅ Ubuntu 18.04+, Debian 9+, Fedora 34+

Administrator Access Required:

  • Ability to install software
  • Modify system settings
  • Install extensions

Internet Connection

Requirements:

  • Speed: 5 Mbps minimum (for downloads and AI)
  • Stability: Consistent connection preferred
  • Data: ~500MB for initial setup
  • Ongoing: AI features require internet

FAQ: Prerequisites

"I've never coded before. Is this for me?"

Absolutely! This workshop is designed for non-programmers. We use VS Code as a document editor, not a coding tool.

"Do I need to pay for AI services?"

No. Free tiers are available for all AI providers we use. You can complete the entire workshop without spending money.

"What if my computer is old?"

Try it! If your computer can run a web browser, it can likely run VS Code. Performance may vary, but core features work on older hardware.

"Can I use a tablet or Chromebook?"

Limited. VS Code has a web version, but the full desktop experience is recommended for this workshop.

"What if I can't install software?"

Contact us. We may have alternative approaches or can help you request IT permissions.

"Do I need to finish in one sitting?"

No. Content is modular. Take breaks, return later. Your progress saves automatically.
